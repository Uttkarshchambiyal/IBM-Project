## 💬 About

A **Chat UI** project developed by team **Cloud Coders** as part of an IBM project. The goal was to build a clean, functional, and user-friendly chat interface focused on:

- 💬 Real-time messaging UI
- 🧹 Clean and minimal layout design
- 📱 Responsive structure for multiple screen sizes
- ⚙️ Basic interaction features and input handling
